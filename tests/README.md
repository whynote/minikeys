[English](README.en.md)

验证使用 Windows 自带的 .NET Framework 编译器，不下载依赖。先在项目目录执行 `.\build.ps1`。

无需交互桌面的测试：

```powershell
.\tests\run.ps1 -ModelOnly
```

此模式验证按键解析、配置读写、旧配置迁移、中英文界面选择、五图标工具条、布局、淡化和最小化时的配置保存。新配置应为中文、微信语音、竖排 60×244px，且启用闲置淡化、淡化后不透明度为 30%；已有配置应保留原有选择。它创建隐藏窗体，不显示窗口、不移动鼠标，也不发送输入或触发语音快捷键。竖排覆盖 40–284px 的宽度和工具条折行临界值，并检查窄竖排改回横排时工具条立即恢复单行。最低尺寸下的按钮不得重叠或越界，按键不得小于 24×24px。

淡化测试使用指定时间调用更新方法，验证 4 秒延迟、渐变、30% 默认值和 20%/65%/70%/100% 自定义不透明度，以及鼠标回来、交互中、设置对话框打开和关闭淡化时恢复全亮。界面语言分别验证中文和英文选择，不依赖 Windows 显示语言；设置对话框验证保存选择、默认值及控件边界。隐藏组件测试覆盖 `WindowState`、`RestoreBounds` 与保存结果；它不代表实际任务栏恢复、桌面输入焦点或语音输入已经通过验证。

测试会用 `DrawToBitmap` 绘制窗体和各个实际子控件，生成 `docs/images/v1.2.0.png`（默认竖排）与 `docs/images/v1.2.0-vertical.png`（最小竖排）。这些是组件渲染预览，不是桌面截图，也不展示透明度合成。中英文设置通过隐藏组件断言检查；原生隐藏下拉框不能可靠生成预览，因此不输出设置图片。

需要可交互桌面和中文输入法的完整测试：

```powershell
.\tests\run.ps1
```

完整模式先执行以上检查，再创建自己的临时文本窗，通过真正的鼠标和键盘输入检查焦点保持、3/E/D/C、Shift、中文拼音、原生边缘缩放、顶部移动、置顶、最小化与程序恢复后的输入；约 8 秒后关闭。它不点击麦克风或测试语音。不要在此期间操作鼠标键盘。当前输入法须支持 `ce` 拼音转换；测试不会更改系统输入法。如果临时文本窗无法取得前台焦点，测试会在发送输入前失败。任务栏按钮的鼠标恢复仍需手动验证。

所有配置写入 `tests\tmp-<随机值>`，结束后删除，不触及正式配置或现有文档。完整模式还会更新 `tests/preview.png`。
