# 迷你补键盘 / MiniKeys v1.2.0

一个程序切换微信和 Windows 语音输入，补全界面语言及淡化参数设置。

- **语音按钮**：工具栏最左增加麦克风，窄竖排时保持第一位。设置中选择微信或 Windows 微软语音输入，默认微信，无需分版下载。
- **微信语音**：点一次保持 Ctrl + Win，再点一次释放；保持期间按钮为红色并暂停淡化。其他补键、窗口操作和正常退出前自动释放组合键。
- **Windows 语音**：每次点击完整发送 Win + H，监听状态由 Windows 控制。
- **中英文切换**：默认中文，设置中可选 English；保存后立即生效并记住选择。
- **淡化可调**：开关默认选中，闲置 4 秒后淡化；不透明度可设为 20%–100%，默认 30% 不透明度，数值越大越清楚。
- **默认竖排**：四键一列，初始 60 × 244 像素；仍可拖动缩放，工具图标自动折行。设置入口改为闭合八齿齿轮。

**下载：**解压本页的 `MiniKeys-v1.2.0-win-portable.zip`，运行 `MiniKeys.exe`。先点击目标输入框，再点击浮窗补键或麦克风。升级前先退出旧程序；已有配置会继续沿用，上述默认值用于首次运行或缺少对应配置的情况。

微信语音此前已由用户亲测可用；本次发布未重新触发语音或录音，也未实测 Windows 语音输入及 Windows 11。完整桌面输入和实际任务栏恢复后的焦点行为未在本次发布重新验证。MiniKeys 只发送快捷键，不访问麦克风，也不发送聊天消息。

76 项不触发语音的配置及界面组件检查通过，覆盖默认值、配置升级、语言保存及即时刷新、淡化参数和紧凑布局。

## English

One application for WeChat and Windows voice input, with manual interface language selection and configurable idle opacity.

- **Microphone control:** first in the toolbar, including narrow vertical layouts. Select WeChat or Windows voice input in settings; WeChat is the default. There are no separate builds to download.
- **WeChat voice input:** click to hold Ctrl + Win, then click again to release. The control turns red while held and fading is suspended. Release automatically before other keys, window actions, and normal exit.
- **Windows voice input:** each click sends a complete Win + H shortcut. Windows manages listening state.
- **Chinese / English interface:** Chinese by default. Select English in settings and save to apply immediately and remember the choice.
- **Configurable fading:** enabled by default after 4 seconds away. Set idle opacity from 20% to 100%, default 30% opacity. Higher values keep the window clearer.
- **Vertical by default:** four keys in one column, initially 60 × 244 pixels. Move and resize as before; toolbar icons wrap. Settings now uses a closed eight-tooth gear.

**Download:** extract `MiniKeys-v1.2.0-win-portable.zip` from this release and run `MiniKeys.exe`. Focus the target text field before clicking a key or the microphone. Close the old application before upgrading. Existing saved preferences are retained; defaults apply on first launch or when a setting is missing.

The user verified the previous local WeChat behavior. Voice input and recording were not triggered again for this release. Windows voice input and Windows 11 have not been tested. Full desktop input and focus behavior after a real taskbar restore have not been rerun. MiniKeys only sends shortcuts; it does not access the microphone or send chat messages.

76 configuration and UI component checks pass without triggering voice input, covering defaults, migration, saved language and immediate UI refresh, fading parameters, and compact layouts.
