# 迷你补键盘 / MiniKeys v1.1.0

第二版让浮窗更小、更安静：图标工具栏、闲置淡化、最小化，以及自动中英文界面。

- **图钉置顶**：用图标代替文字，蓝色表示置顶；齿轮打开设置，短横线最小化，叉号退出。
- **窄条布局**：工具图标会随宽度自动折行，四键竖排最窄可缩至 40 像素；拖顶部短槽移动。
- **柔和淡化**：鼠标离开窗口 4 秒后，约 0.4 秒平滑淡至 65% 不透明度；鼠标回来或交互立即恢复清晰。可在设置中关闭。
- **最小化**：收起到任务栏，点击任务栏图标恢复原位置和尺寸。恢复后先点击目标输入框，再使用补键。
- **自动中英文**：跟随 Windows 显示语言，中文系统显示中文，其余语言显示英文。

**下载：**本页的 `MiniKeys-v1.1.0-win-portable.zip`，解压后运行 `MiniKeys.exe`。先点击目标输入框，再点击浮窗按键。从 v1.0.0 升级时先退出旧程序；原按键和窗口配置会保留，新增淡化默认开启。

适用于 Windows 10 / 11，使用 Windows 的 .NET Framework 4 系列运行环境，无需安装。Windows 11 尚未实测。

验证：44 项无桌面自动检查通过，包含配置迁移、紧凑布局、淡化及最小化保存。本轮未重跑完整鼠标/输入法桌面测试，任务栏点击恢复后的焦点行为尚待实测；恢复后请先点击目标输入框。

## English

Version 1.1 makes MiniKeys smaller and less distracting, with icon controls, idle fading, minimization, and an automatic English interface.

- **Pin icon:** blue means always on top. The gear opens settings, the horizontal line minimizes, and the cross exits.
- **Narrow layout:** toolbar icons wrap as you shrink the window, making the four-key vertical keypad fit into a strip as narrow as 40 pixels. Drag the small top grip to move it.
- **Gentle fading:** after the pointer has been outside for 4 seconds, fade smoothly over about 0.4 seconds to 65% opacity. Hover or interact to restore full opacity immediately. Turn it off in settings if preferred.
- **Minimize:** hide the keypad in the taskbar, then click the taskbar icon to restore its previous position and size. After restoring, click the target text field before using the keypad.
- **Automatic language:** use Chinese on Chinese-language Windows systems, and English on all others.

**Download:** extract `MiniKeys-v1.1.0-win-portable.zip` from this release and run `MiniKeys.exe`. Click your target text field before clicking the keypad. When upgrading from v1.0.0, close the old app first. Existing keys and window settings are retained; idle fading is enabled by default.

Designed for Windows 10 / 11 with the .NET Framework 4 family runtime. No installation required. Windows 11 has not been tested.

Validation: 44 automated checks pass without desktop interaction, covering migration, compact layouts, fading, and saving normal bounds while minimized. The full mouse/IME test and focus behavior after an actual taskbar restore have not been rerun for this release. Click the target text field after restoring.
