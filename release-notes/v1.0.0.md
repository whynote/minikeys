# 迷你补键盘 / MiniKeys v1.0.0

首个公开版本：只把需要的几个按键放在屏幕上，方便补上实体键盘失灵的键。

- 默认 `3 E D C`，可自定义 1–24 个按键、每行 1–12 个。
- 默认悬浮置顶，点击按键时保持原输入框焦点，可继续中文拼音输入。
- 拖动顶部移动，拖动边缘缩放，自动记住位置、尺寸和按键配置。
- 便携版，无需安装，使用 Windows 的 .NET Framework 4 系列运行环境。

**开始使用：**下载本页的 `MiniKeys-v1.0.0-win-portable.zip`，解压后运行 `MiniKeys.exe`。先点击目标输入框，再点击悬浮按键。点击“设置”自定义，点击“已置顶 / 置顶”切换置顶，点击 `×` 退出。

支持目标为 Windows 10 / 11；Windows 10 已实测中文拼音、焦点保持和拖动缩放，Windows 11 尚未实测。v1.0.0 的界面为中文，仓库提供完整英文操作说明。

## English

The first public release of MiniKeys: a small floating Windows keypad for the few keys your physical keyboard can no longer type.

- Starts with `3 E D C`. Customize 1–24 keys and 1–12 columns.
- Stays on top by default and preserves the target text field's focus when you click a key. Works with the active input method, including Chinese Pinyin.
- Drag the top bar to move, or drag an edge to resize. Keys, layout, position, size, and the pinned state are saved automatically.
- Portable; no installation required. Uses the Windows .NET Framework 4 family runtime.

**Get started:** download `MiniKeys-v1.0.0-win-portable.zip` attached to this release, extract it, and run `MiniKeys.exe`. Click your target text field, then click the floating keys. **设置** opens settings; **已置顶 / 置顶** toggles always-on-top; **×** exits.

Designed for Windows 10 / 11. Chinese Pinyin input, focus preservation, moving, and resizing have been tested on Windows 10; Windows 11 has not been tested. **The v1.0.0 application interface is in Chinese.** The repository includes a complete [English guide with a control translation table](https://github.com/whynote/minikeys/blob/v1.0.0/README.en.md).
