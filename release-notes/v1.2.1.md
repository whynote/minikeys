# 迷你补键盘 / MiniKeys v1.2.1

托盘版本正式发布，并为 EXE、窗口和托盘统一加入原创蓝底白色迷你键盘图标。

- **不占 Alt+Tab 和任务栏**：浮窗继续悬浮使用，窗口切换列表保持简洁。
- **系统托盘找回**：短横线收起到右下角托盘；左键点击键盘图标，或右键选择“显示键盘”恢复。叉号或托盘菜单“退出”关闭程序。
- **专属应用图标**：内嵌多个尺寸，文件、窗口和托盘使用同一设计，便携运行不需要外置图标文件或新依赖。
- **保留原有功能与设置**：默认中文、微信语音、竖排、30% 不透明度及淡化开启；语言和语音方式仍可在设置中切换。
- **更低的不透明度**：淡化参数范围放宽为 1%–100%，默认仍为 30%。

**下载：**解压本页的 `MiniKeys-v1.2.1-win-portable.zip`，运行 `MiniKeys.exe`。升级前先通过叉号或托盘菜单退出旧程序；已有配置会继续沿用。托盘图标可能位于右下角隐藏图标区域。从托盘恢复后，请先点击目标输入框，再使用补键或语音。

用户已亲测此前的托盘版本可用。本轮没有重新触发语音测试；Windows 语音输入及 Windows 11 仍未实测。MiniKeys 只发送快捷键，不访问麦克风，也不发送聊天消息。

97 项配置及组件检查通过，覆盖自定义图标、托盘释放和最低 1% 不透明度；没有显示测试窗口或触发语音。

## English

The tray version is now published, with an original blue-and-white mini-keyboard icon for the executable, window, and system tray.

- **No Alt+Tab or taskbar entry:** keep using the floating keypad without adding a window-switching item.
- **System-tray access:** minimize with the short horizontal line. Left-click the keyboard icon, or choose **Show keyboard** from its right-click menu, to restore. Exit with the cross or tray menu.
- **Dedicated app icon:** multiple sizes are embedded in the app, with the same design for files, the window, and the tray. Portable use needs no external icon file or new dependency.
- **Existing behavior retained:** default to Chinese, WeChat voice input, a vertical layout, and enabled fading to 30% opacity. Choose interface language and voice method in settings.
- **Lower opacity values:** the idle-opacity range is now 1%–100%; the default remains 30%.

**Download:** extract `MiniKeys-v1.2.1-win-portable.zip` from this release and run `MiniKeys.exe`. Close the previous app through its cross or tray menu before upgrading; saved preferences are retained. The tray icon may be in the hidden-icons area. After restoring, focus the target text field before clicking a key or voice button.

The user confirmed the earlier tray version works in actual use. Voice tests were not triggered again for this icon update. Windows voice input and Windows 11 remain untested. MiniKeys only sends shortcuts; it does not access the microphone or send chat messages.

97 configuration and component checks pass, covering custom icons, tray cleanup, and opacity down to 1%, without showing test windows or triggering voice input.
