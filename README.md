# 迷你补键盘 · MiniKeys

<img src="assets/minikeys.svg" width="64" height="64" alt="MiniKeys 迷你键盘图标">

**把坏掉的几个按键，变成随手可点的悬浮按钮。**

[English documentation](README.en.md) · [下载最新版本](https://github.com/whynote/minikeys/releases/latest) · [中文版本说明](CHANGELOG.md) · [English release notes](CHANGELOG.en.md)

MiniKeys 是一个轻量的 Windows 悬浮补键工具。默认显示 **3、E、D、C** 四个按键，也可以换成自己需要的按键。把它放在屏幕一角，用鼠标补上失灵的实体按键，或点击麦克风调用微信、Windows 的语音输入。

![迷你补键盘 v1.2.0 默认竖排界面](docs/images/v1.2.0.png)

v1.2.1 沿用上方布局，应用、窗口和托盘统一使用蓝底白色迷你键盘图标。

默认中文界面、微信语音、四键竖排，初始尺寸为 **60 × 244 像素**。设置中可切换 **English**，保存后立即生效并记住选择；界面语言与语音方式分别设置。

## 下载与开始使用

1. 打开 [Releases 下载页](https://github.com/whynote/minikeys/releases/latest)，下载 `MiniKeys-v1.2.1-win-portable.zip` 并解压。
2. 双击 `MiniKeys.exe`。无需安装，默认置顶。
3. 先点击要输入的聊天框、文档或其他输入位置，再点击浮窗上的按键。

程序发送真实的按键事件，字母交给当前输入法处理：中文模式下可继续打拼音，英文模式下输入英文字母。按钮显示的是大写键名，输入大小写跟随实体键盘的 Shift / Caps Lock 状态。

适用于 Windows 10 / 11，使用 Windows 的 .NET Framework 4 系列运行环境，不依赖 Java、Python 或第三方包。中文拼音、焦点保持、移动和缩放已在 Windows 10 实测；**Windows 11 尚未实测。**

## 可以做什么

- **只保留需要的键**：自定义 1–24 个按键及顺序，每行 1–12 个。
- **一个程序，两种语音方式**：在设置中选择微信语音输入或 Windows 微软语音输入，默认微信。麦克风位于工具栏最左侧，窄竖排时保持第一位。
- **中英文界面切换**：默认中文，可手动选择 English，保存后立即生效。
- **图标工具栏**：麦克风、图钉、齿轮、最小化和关闭；蓝色图钉表示已置顶。
- **可调闲置淡化**：鼠标离开窗口 4 秒后平滑淡化，默认开启并降至 **30% 不透明度**。可关闭，或在 1%–100% 不透明度之间调整；数值越大越清楚，鼠标回来或交互立即恢复清晰。
- **保持输入焦点**：点击补键时，原输入框继续接收按键。
- **紧凑竖排**：工具图标随宽度自动折行。拖顶部短槽移动，拖窗口边缘或右下角缩放。
- **不占窗口切换列表**：浮窗不显示在 Alt+Tab 和任务栏中，系统托盘保留找回入口。
- **托盘收起与恢复**：点击短横线收进右下角托盘，点击托盘键盘图标恢复原位置和尺寸。
- **专属应用图标**：蓝底白色迷你键盘图标内嵌于 EXE、窗口和托盘，便携运行时不需要额外图标文件。
- **记住配置**：下次启动恢复按键、排列、位置、尺寸、置顶、语言、语音方式和淡化设置。

## 设置

点击齿轮打开设置。按键用空格分隔，例如：

```text
3 E D C Space Backspace
```

“每行按键数”设为 `1` 即竖排，设为 `4` 即四键横排，设为 `2` 即两列。“恢复 3 E D C”恢复默认四键和一列排列；点击“保存”应用设置。

界面语言可选中文或 English，与语音输入方式无关。默认开启闲置淡化；“淡化后不透明度”数值越大越清楚，100% 表示始终清晰。微信快捷键保持期间不会淡化。

支持以下按键，名称不区分大小写：

| 类型 | 可填写的名称 |
| --- | --- |
| 字母、数字 | `A`–`Z`、`0`–`9` |
| 功能键 | `F1`–`F12` |
| 编辑键 | `Space`、`Enter`、`Backspace`、`Tab`、`Esc`、`Delete` |
| 方向与导航 | `Left`、`Right`、`Up`、`Down`、`Home`、`End`、`PageUp`、`PageDown` |
| 英文标点 | `-`、`=`、`[`、`]`、`;`、`'`、`,`、`.`、`/`、`\`、反引号 |

标点结果跟随当前键盘布局及输入法。每个补键按钮发送单个按键，可配合实体键盘上的 Shift / Ctrl 使用。

## 语音输入

**微信语音输入（默认）**：打开并登录支持此功能的电脑版微信，点击目标输入框，再点击麦克风。程序保持 **Ctrl + Win**；说完后再次点击麦克风释放。红色只表示 MiniKeys 正保持快捷键，不代表已读取到微信的录音状态。点击其他补键、设置、图钉、最小化、移动/缩放或正常退出时，会先释放组合键。操作实体键盘前，也请先点击麦克风结束。

**Windows 微软语音输入**：在设置中切换，点击目标输入框后点击麦克风。每次点击完整发送一次 **Win + H**，由 Windows 管理语音输入状态。

微信模式此前已由用户亲测可用；本次发布未重新触发语音或录音，也未实测 Windows 语音输入。快捷键来源、操作细节与英文说明见 [VOICE-INPUT.md](VOICE-INPUT.md)。

## 常见操作与问题

| 需要做什么 | 操作 |
| --- | --- |
| 移动浮窗 | 拖动顶部短拖动槽 |
| 调整大小 | 拖动窗口边缘或右下角 |
| 取消或恢复置顶 | 点击图钉；蓝色表示已置顶 |
| 临时收起 | 点击短横线图标，收进右下角系统托盘 |
| 恢复或找回窗口 | 点击托盘里的键盘图标，或右键选择“显示键盘”；图标可能在隐藏图标区域中 |
| 切换界面语言、语音方式或调整淡化 | 点击齿轮图标 |
| 退出 | 点击叉号图标，或右键托盘图标选择“退出” |
| 恢复全部默认设置 | 退出后删除 `%LOCALAPPDATA%\MiniKeys\settings.json`，再启动 |

从托盘恢复后，先点击要输入的目标输入框，再点击补键。如果点击按键没有输入，先点击目标输入框；若目标程序以管理员身份运行，补键盘也需要以相同权限运行。

升级时先退出旧程序，再打开新版。已有按键、窗口、语音和淡化配置会继续沿用；默认值用于首次运行或缺少对应配置的情况，不会覆盖已保存的选择。历史版本仍可从 [Releases](https://github.com/whynote/minikeys/releases) 下载。

MiniKeys 通过 Windows `SendInput` 发送按键事件，不联网、不读取或修改剪贴板、不监听或记录输入内容。语音识别由微信或 Windows 执行；MiniKeys 只发送快捷键，不访问麦克风，也不发送聊天消息。配置只保存在本机的 `%LOCALAPPDATA%\MiniKeys\settings.json`。

## 从源码编译

在项目目录运行 PowerShell：

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

无参数构建统一的 `MiniKeys.exe`，语音方式在程序设置中切换。源码位于 [src/MiniKeys.cs](src/MiniKeys.cs)，中英文验证说明见 [tests/README.md](tests/README.md) 和 [tests/README.en.md](tests/README.en.md)。上方图片由程序组件绘制生成，不是桌面截图，不展示透明度合成。

托盘试用版此前已由用户实际使用确认可用；本次发布加入专属应用图标，没有重新触发语音测试。Windows 语音输入及 Windows 11 仍未实测。

97 项不触发语音的配置及组件检查通过，包含内嵌图标、EXE 图标提取、托盘清理，以及 1%–100% 不透明度范围。
